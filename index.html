Portafolio Subidas

Internal tool used by Pau Subirana to manage his own YouTube channels (El Veredicto, Delatados and other Spanish-language documentary channels he owns). It is a command-line script that runs only on the owner's computer and uses YouTube API Services (YouTube Data API v3) to upload his videos, set thumbnails, captions, titles, descriptions and localized metadata, declare synthetic content and schedule publication. Not a public service: no one else signs in or uses it.

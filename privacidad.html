Política de privacidad

Última actualización: 1 de noviembre de 2026.

«Portafolio Subidas» es una herramienta interna que usa únicamente su propietario, Pau Subirana, para gestionar sus propios canales de YouTube.

Qué datos usa

Con el permiso que el propietario concede mediante OAuth de Google, la herramienta accede a la API de datos de YouTube para subir, leer y modificar los vídeos de sus propios canales: el vídeo, miniaturas, subtítulos, títulos, descripciones, etiquetas, idiomas y fecha de publicación.

Qué no hace

No recoge, vende ni comparte datos personales de nadie. No accede a datos de espectadores ni de otros usuarios. No usa cookies ni analítica.

Almacenamiento

El token de acceso se guarda solo en el ordenador del propietario y nunca se envía a terceros. La herramienta no guarda datos de YouTube: solo consulta el estado de los vídeos que sube. El token se borra del ordenador cuando deja de usarse. Se puede revocar en cualquier momento en myaccount.google.com/permissions.

Servicios de YouTube

La herramienta usa los Servicios de API de YouTube. Se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

Privacy policy (English)

"Portafolio Subidas" is an internal tool used only by its owner, Pau Subirana, to manage his own YouTube channels. With the owner's OAuth consent it uses the YouTube Data API to upload, read and update videos on his own channels (video files, thumbnails, captions, titles, descriptions, tags, localizations and publish time). It does not collect, sell or share anyone's personal data, does not access viewers' or other users' data, and uses no cookies or analytics. The access token is stored only on the owner's computer and is deleted from that computer when no longer needed. The tool stores no YouTube data; it only reads the status of the videos it uploads. Access can be revoked at myaccount.google.com/permissions. This tool uses YouTube API Services; the YouTube Terms of Service and Google Privacy Policy apply. Contact: subiranapau@gmail.com

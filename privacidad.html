Privacy policy

Last updated: 5 November 2026.

"Portafolio Subidas" is an internal command-line tool used only by its owner, Pau Subirana, to manage his own YouTube channels. It is not offered to anyone else.

YouTube API Services

This tool uses YouTube API Services. By using it, the owner is bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

What information the tool accesses

With the OAuth consent the owner grants for each of his channels (scope youtube.force-ssl), the tool uses the YouTube Data API to upload videos to those channels and to read and update their own metadata: video file, thumbnail, caption files, title, description, tags, localized titles and descriptions, privacy status, synthetic-content declaration and publish time. It does not access data of viewers, commenters or any other user.

How it is used, stored and shared

  • The information is used only to publish and schedule the owner's own videos.
  • The only thing stored is the OAuth refresh token of each channel, in a file on the owner's own computer (readable only by the owner). No YouTube data is stored: the tool reads the status of a video only to check that an upload or update finished.
  • Nothing is sold or shared with third parties. The tool has no server, no cookies and no analytics.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked or the tool stops being used, the local token files are deleted within 7 days. Since the tool keeps no other data, nothing else needs to be deleted. Any deletion request can be sent to the contact below and is completed within 7 days.

Política de privacidad (español)

Última actualización: 5 de noviembre de 2026.

«Portafolio Subidas» es una herramienta interna de línea de comandos que usa únicamente su propietario, Pau Subirana, para gestionar sus propios canales de YouTube. No se ofrece a nadie más.

Servicios de API de YouTube

La herramienta usa los Servicios de API de YouTube. Al usarla, el propietario acepta las Condiciones del Servicio de YouTube. También se aplica la Política de Privacidad de Google.

A qué datos accede

Con el permiso OAuth que el propietario concede para cada uno de sus canales (ámbito youtube.force-ssl), la herramienta usa la API de datos de YouTube para subir vídeos a esos canales y leer y modificar sus propios metadatos: archivo de vídeo, miniatura, subtítulos, título, descripción, etiquetas, títulos y descripciones traducidos, privacidad, declaración de contenido sintético y fecha de publicación. No accede a datos de espectadores, comentaristas ni de ningún otro usuario.

Uso, almacenamiento y cesión

  • Los datos solo se usan para publicar y programar los vídeos del propietario.
  • Lo único que se guarda es el token OAuth de cada canal, en un fichero del ordenador del propietario (solo él puede leerlo). No se guardan datos de YouTube: la herramienta solo consulta el estado de un vídeo para comprobar que una subida o un cambio terminó.
  • No se vende ni se cede nada a terceros. La herramienta no tiene servidor, ni cookies, ni analítica.

Revocar el acceso y borrar datos

El acceso se puede revocar en cualquier momento en la página de seguridad de Google: https://security.google.com/settings/security/permissions. Al revocarlo o dejar de usar la herramienta, los tokens locales se borran en un máximo de 7 días. Como no se guarda nada más, no hay otros datos que borrar. Cualquier petición de borrado se puede enviar al contacto de abajo y se atiende en un máximo de 7 días.
